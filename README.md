# TAIGCIQA-10K Dataset


Official dataset repository for:

**ThemeIQA: Theme-Oriented Generated Image Quality Assessment**

IEEE Transactions on Image Processing


## Overview

TAIGCIQA-10K is a large-scale dataset for theme-oriented quality assessment of generated image sets.

Different from existing AIGC image quality assessment datasets that mainly focus on individual images, TAIGCIQA-10K considers both individual image quality and cross-image relationships under the same theme.


## Dataset

The dataset is publicly available at:

https://pan.baidu.com/s/1xkASWd5WJxFgJIOhJVgmeQ


## Dataset Statistics

TAIGCIQA-10K contains:

- 10,796 generated images
- corresponding text prompts
- subjective quality annotations


The annotations include:

- Perceptual Quality
- Text-Image Alignment
- Subject Consistency
- Scene Richness
- Theme-Oriented Quality
